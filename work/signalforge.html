SignalForge / Inspect the evidence

When three articles are still one source

Repeated coverage can resemble independent corroboration. SignalForge keeps source relationships and counter-evidence attached to the claim being assessed.

Synthetic demonstration · Reproduced 16 October 2026 · Development project

01 / The input

Three synthetic articles support the same claim and explicitly cite one primary source. A separate test report is then added, followed by a report that refutes the claim. Provenance and stance are supplied explicitly.

02 / The result

Synthetic example — selected results

The three articles initially count as one supporting family. Independent support changes the status to corroborated; explicit counter-evidence changes it to contested. Each stage retains exact evidence and claim identifiers.

03 / What this means for a review

The useful output is an inspectable basis for judgment: which claims have support, where that support originates, and what challenges it. A decision can cite a particular snapshot and be revisited as evidence changes.

What this establishes — and its limits

Corroborated is a rule-based status based on supplied provenance, not proof of truth. Hidden dependence and semantic paraphrases are not automatically resolved. This demonstration runs the pure adjudicator offline; it does not validate live collectors. The general-web collector remains an opt-in mock, scores are uncalibrated heuristics, and local hashes are not external signatures.

This is an independently developed engineering example, not a client engagement or production validation.

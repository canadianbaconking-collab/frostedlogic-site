Coldgate / Inspect declared authority

When a configuration grants more authority

A small configuration change can remove approval requirements and broaden declared access. Coldgate makes those changes visible for review.

Synthetic demonstration · Reproduced 16 October 2026 · Development project

01 / The input

An issue-creation tool moves from one named repository to a wildcard, while its declared approval requirement changes from required to not required.

03 / What this means for a review

These are specific questions for a configuration review: is the broader scope intended, who can approve it, and what independently verifies the effective controls? Credential names alone cannot establish privilege.

What this establishes — and its limits

This example uses saved synthetic reports with Coldgate overlay declarations, not standard MCP enforcement controls. Static claims do not prove runtime behaviour. Coldgate does not execute tools or enforce approvals. Its effect inference is conservative; the documented small holdout detected 1 of 4 consequential effects. Independent pilot results remain unrecorded.

This is an independently developed engineering example, not a client engagement or production validation.
